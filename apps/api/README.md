# Shared NightShift test backend

One NestJS API serves Customer and Listener in the same Android app. PostgreSQL owns users, revocable sessions, approvals, calls, unique participant claims, fixed-point test journals, reports, blocks and the outbox. Redis owns 45-second online presence and the test sign-in limiter. The development seed creates only three explicitly fictional identities; it cannot approve real listeners.

Run the root setup instructions first, then `npm run build`, `npm run db:migrate`, `npm run db:seed`, and `npm start` from this directory. Scripts load the ignored root `.env` using Node 24. The API listens on port 3000 by default. All application routes except health and development sign-in require `Authorization: Bearer <session>`.

`npm test` runs tariff/configuration checks. `npm run test:integration` uses the configured local PostgreSQL/Redis, creates a random isolated database schema, applies migrations, seeds twice, and destroys only that schema afterward. Set `TEST_DATABASE_URL` to a separate test database in CI. These tests use server-controlled time and synthetic media-readiness acknowledgments; they prove control-plane behavior, not audible Agora media.

Use `customer`, `customer2`, and `listener` as test handles. The private `DEV_ACCESS_KEY` must contain at least 24 characters. The session token is random, hashed at rest, expires after 12 hours and is revoked by logout or a fresh login. Only one device session per fixture is allowed; signing in elsewhere during an active call is refused. Do not expose this test API publicly. All non-development/test environments fail startup until production authentication, policy and provider controls are implemented.

Agora credentials (`AGORA_APP_ID`, `AGORA_APP_CERTIFICATE`) stay on the backend. RTC tokens authorize the session's opaque channel and participant UID 1 or 2 for at most 120 seconds. Never enable App-ID-only joining on the provider project. Missing credentials produce `RTC_UNAVAILABLE`; there is no successful mock audio response. The certificate is never returned to the app or written to logs.

The audio test tariff deliberately matches `audio/billing.mjs`: through 40 healthy seconds costs zero; after 40 seconds the minimum is 60 test credits; after 60 seconds charge the cumulative ceiling of seconds. A credit is 60,000 integer microcredits. Private video uses the separate `test-video-v1` fixture at 120 coins/minute, the same free threshold and 60-second minimum. At invitation time the backend holds at most 600 audio or 1,200 video test credits and caps the call at 600 delivered seconds (or the smaller affordable duration), using the chosen immutable rate snapshot. It posts one balanced journal settlement and releases the unused hold. Earnings shown are a separate, nonredeemable illustration based on actual delivered milliseconds at 50,000 paise per hour, rounded once. Any free-call illustration is offset by the `subsidy:test` account; no payout or real liability is created.

`VIDEO_CALLS_ENABLED=false` by default. Enabling it still requires valid private Agora configuration and cannot enable production startup. Authenticated `GET /v1/rtc/config` returns only the public app ID, video-enabled boolean and test-only marker; disabled/unconfigured responses contain a null app ID. Video creation and acceptance require each participant's explicit `videoConsent:true`, recorded as immutable consent timestamps. Media readiness for video also requires `videoReady`; audio-only readiness never authorizes healthy video time. Turning the flag off makes recovery end existing video calls. Audio fallback ends the video call and begins a separately quoted audio invitation; rates do not change in place. These controls are cooperative test-app controls, not proof of provider enforcement against a modified client.

Both clients must report media readiness, then heartbeat every two seconds. Only the time through both latest confirmed heartbeats counts. A missing heartbeat pauses at the last confirmed boundary; reconnect gaps and ringing are excluded. No client-supplied duration or rate is accepted. A 45-second failed join/reconnect ends the session; an absolute session cap also prevents unlimited reconnect. Provider participation/QoS evidence and independently enforced immediate provider cutoff remain paid-launch blockers. Short-lived tokens alone are **not** claimed to prove immediate forced cutoff.

REST polling of `/v1/snapshot` and `/v1/calls` restores durable state. Optional Socket.IO uses WebSocket transport, handshake `auth: {token}`, and private user rooms. Every connected session is revalidated each second. `call.invited` and `call.state_changed` contain the call snapshot plus event ID/time; `/v1/events` returns participant-authorized durable event envelopes. Delivery is at-least-once; clients deduplicate by event ID/version.

Foreground two-phone testing, real Agora audio, network switching, audio route changes, background notifications, media revocation, provider callbacks, and store/OTP approvals are not implied by automated backend tests. See the repository milestone evidence and device checklist.
